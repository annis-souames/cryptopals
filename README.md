### How to run:

Each set is a go package, and each challenge is a test file, you can run it via `go test`:

Example if you want to test challenge 1.3 (so in set1), you can omit `-v` option to hide output and just get the test pass/failure. 

```
go test ./set1/ -run TestCh03 -v 
```
